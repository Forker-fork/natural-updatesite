Natural

Cucumber and JBehave editors for Eclipse — syntax highlighting, outline, content assist, validation and navigation to Java step definitions.

Update site

Paste this URL into Eclipse:

https://forker-fork.github.io/natural-updatesite/
  1. Help → Install New Software…
  2. Click Add…, paste the URL above, give it the name Natural, click Add
  3. Tick Cucumber and Jbehave
  4. Next → Finish, then restart Eclipse

Requirements

Eclipse2025-12 or later (tested on 2026-06 / 4.40)
Java25
Xtext2.43 (ships with the Eclipse release train)

Version 2.0.0 is a breaking release. Java 8 is no longer supported and the minimum Eclipse version is now 2025-12, because Xtext 2.43 requires it. Older IDEs cannot install this build.

Included features

  • Cucumber Editor — .feature files
  • JBehave Editor — .story files

Step definition navigation

Ctrl+click a step in a .feature file to jump to its Java method. This requires step definitions annotated from io.cucumber.java.en in an open Java project in the same workspace, and the annotation value must be a regular expression:

@Given("^I have (\d+) cukes$")   ← resolves
@Given("I have {int} cukes")      ← Cucumber Expressions are not supported

The Gherkin keyword is not part of the match, so the same step text works under Given, When, Then, And or But.

Known limitations

  • Cucumber Expressions ({int}, {string}…) are skipped — use regex
  • Only the io.cucumber.java.en annotation package is recognised
  • .story files have no Ctrl+click navigation
  • English Gherkin keywords only; no * step keyword
